Welcome to Protein_Area's documentation!
=========================================================

Protein_Area calculates the protein cross-sectional area in successive
z-direction slices of a molecular dynamics trajectory. It uses two-dimensional
Voronoi cells to estimate each protein atom's share of the area, with periodic
images enabled by default.

Start with :doc:`getting_started` for installation and usage examples, or see
the :doc:`api` reference.
